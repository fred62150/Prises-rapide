Installation du serveur (une seule fois)

1. Génère tes clés. Elles s’affichent une seule fois : ne les garde pas ailleurs que dans Supabase.

2. Dans Supabase, ouvre Edge Functions, puis Secrets. Ajoute VAPID_PUBLIC et VAPID_PRIVATE avec ces valeurs, puis VAPID_SUBJECT avec mailto: suivi de ton e-mail.

3. Copie le SQL, colle-le dans l’éditeur SQL de Supabase et exécute-le.

4. Dans Edge Functions, crée une fonction nommée rappels (via l’éditeur), colle le code et déploie-la.

5. Reviens ici, puis clique sur « Activer sur cet appareil » sur chaque appareil.

Ajout rapide par Raccourcis

Un raccourci Apple demande ta phrase, l’envoie à ton serveur, et la tâche apparaît dans l’appli sans l’ouvrir. Le serveur des notifications doit être installé (carte ci-dessus).

Mise en place (une seule fois)

1. Génère un jeton secret, puis ajoute dans Supabase (Edge Functions, Secrets) deux secrets : CAPTURE_TOKEN et CAPTURE_USER, avec les valeurs ci-dessous.

2. Remplace le code de la fonction rappels par la dernière version (« Copier le code de la fonction » plus haut). Dans ses réglages, désactive « Verify JWT », puis déploie.

3. Dans l’app Raccourcis, crée un raccourci : « Demander une saisie » (texte), puis « Obtenir le contenu de l’URL » avec l’adresse ci-dessous, méthode POST, corps JSON.

4. Champs du corps JSON : action = add, token = ton jeton, tz = Europe/Paris, text = la saisie demandée. Termine par « Afficher le résultat » sur le champ summary. Un exemple de corps est prêt à copier :

Pour noter un mémo au lieu d’une tâche : duplique ce raccourci et remplace action = add par action = note. Tu peux écrire #idee, #info, #lien, #lire, #pro ou #perso dans la phrase.

5. Mac : dans les réglages du raccourci, ajoute un raccourci clavier. iPhone : ajoute-le à l’écran d’accueil, ou dis « Dis Siri » suivi de son nom.

Réunions du calendrier

Un raccourci lit le calendrier de ton iPhone ou de ton Mac et envoie tes réunions d’aujourd’hui et de demain à ton serveur. Elles s’affichent en haut de l’appli, avec un bouton « Rejoindre » quand un lien de visio est trouvé. Les notes et les participants ne sont jamais envoyés.

Mise en place du raccourci (une seule fois)

0. Il faut d’abord avoir fait la carte « Ajout rapide par Raccourcis » (jeton et secrets), et mis à jour la fonction rappels avec la dernière version (« Copier le code de la fonction »), puis déployé.

1. Dans l’app Raccourcis, crée un raccourci « Mes réunions ».

2. Ajoute « Trouver des événements de calendrier ». Filtre 1 : « Date de fin » · « est dans les prochains » · 2 jours. Filtre 2 : « Calendrier » · « est » · choisis le ou les calendriers voulus. Trie par date de début.

3. Ajoute « Répéter avec chaque élément ». À l’intérieur, dans cet ordre : « Formater la date » sur la date de début (format ISO 8601), « Formater la date » sur la date de fin (format ISO 8601), puis « Dictionnaire » avec 7 clés de type texte : title = Titre, start = premier résultat formaté, end = second résultat formaté, calendar = Calendrier, location = Lieu, url = URL, notes = Notes.

4. Après la boucle, ajoute « Obtenir le contenu de l’URL » avec l’adresse ci-dessous, méthode POST, corps JSON : action = cal, token = le même jeton que pour l’ajout rapide, tz = Europe/Paris, events = « Résultats de la répétition » (type Tableau).

5. Termine par « Afficher le résultat » sur le champ summary : il indique combien de réunions ont été envoyées.

6. iPhone : onglet Automatisation, « Heure de la journée » (par exemple 7 h et 13 h), « Exécuter immédiatement », puis choisis ce raccourci. Mac : lance-le à la main ou ajoute un raccourci clavier.
